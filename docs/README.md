# Dokumentasi Proyek VIRA (Virtual Run, Ride, & Walk)

Dokumen spesifikasi arsitektur dan perencanaan proyek VIRA telah disusun:

1. [PRD_VIRA.md](./PRD_VIRA.md) — Product Requirement Document lengkap mencakup kebutuhan bisnis, alur pengguna, fitur pendaftaran guest, e-BIB, akumulasi jarak, dan integrasi Tripay & Mailketing.
2. [DATABASE_SCHEMA_VIRA.md](./DATABASE_SCHEMA_VIRA.md) — Skema database lengkap (ERD Mermaid), definisi tabel Laravel Migration, relasi antar tabel, dan indexing.
3. [DESIGN_PLAN_VIRA.md](./DESIGN_PLAN_VIRA.md) — Rencana arsitektur sistem, sequence diagram webhook, state machine submission, service layer Laravel, konsep UI/UX, dan roadmap implementasi.
